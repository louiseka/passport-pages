## What is Passport Pages?
**Passport Pages** is a travel-journal web application built using the **REST Countries API**.  

Users can search for a country they have visited and log their personal experiences in a digital journal called *Passport Pages*. The project was created as part of the **TechNative Digital Software Development Tech Finishing School interview process**.

## Features
- Search for countries using the **REST Countries API**  
- Log personal travel experiences per country  
- Simple and intuitive journal-style interface  
- Clean, user-focused design  

## Technologies Used
- **JavaScript** – Application logic and API handling  
- **RESTful APIs** – Fetching country data  
- **HTML** – Structure and layout  
- **CSS** – Styling and visual design  

### JavaScript Concepts Practiced
- Fetching and handling API data  
- DOM manipulation for dynamic content  
- User input handling and state updates  

## Future Improvements
- Add the ability to **save countries to a wish list**  
- Enable **editing existing journal entries**  
- Allow users to **add images** to journal entries
